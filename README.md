PPM image viewer

This is a ppm image viewer I wrote as a recreational project.

## Building and Running
if you're on nix os:
```bash
nix develop
```
else ensure you have the following installed:
1. Raylib
2. Rust Compiler
3. Make

![NOTE]
> Raylib should be in a path that the rust compiler can find

Then run:
```bash
make
```
